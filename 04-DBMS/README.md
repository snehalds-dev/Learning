# DBMS — Learning Guide

This folder is a concise learning and revision guide for **Database Management Systems (DBMS)**.

The purpose of this section is to organize important **database terminologies, concepts, principles, and techniques** in a simple and revision-friendly format.

This folder covers topics such as:

* Relational Database Concepts
* SQL and Queries
* Keys and Constraints
* Normalization
* Transactions
* ACID Properties
* Concurrency Control
* Indexing
* Joins
* Views and Stored Procedures
* Database Design
* SQL vs NoSQL
* Common DBMS concepts asked in technical interviews

The goal is to build a strong understanding of **how data is stored, organized, queried, and managed**, while keeping the material concise and practical for development and interview preparation.
