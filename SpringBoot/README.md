# Spring Boot — Learning Guide

This folder is a concise learning and revision guide for **Spring Boot**.

The purpose of this section is to document important **terminologies, concepts, annotations, configurations, design patterns, and commonly used features** of Spring Boot in a simple and easy-to-review format.

Use this folder to:

* Understand core Spring Boot concepts and terminology.
* Quickly revise important annotations and configurations.
* Review commonly used Spring concepts such as Dependency Injection, IoC, Beans, REST APIs, and Spring MVC.
* Maintain practical examples and notes for concepts that are frequently used in development and interviews.
* Refer back to concepts quickly instead of going through lengthy documentation or tutorials.

The goal is to keep the content **clear, concise, practical, and revision-friendly**.
