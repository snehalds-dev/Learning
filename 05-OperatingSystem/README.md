# Operating System — Learning Guide

This folder is a concise learning and revision guide for **Operating System concepts**.

The purpose of this section is to organize important **terminologies, concepts, mechanisms, and principles** of operating systems in a simple and easy-to-review format.

This folder covers topics such as:

* Processes and Threads
* Process Scheduling
* Synchronization and Concurrency
* Deadlocks
* Memory Management
* Virtual Memory
* Paging and Segmentation
* File Systems
* CPU and I/O Management
* Inter-Process Communication
* Common Operating System concepts asked in technical interviews

The goal is to build a strong conceptual understanding of how operating systems manage **processes, memory, resources, and hardware**, while keeping the material concise and useful for quick revision.
