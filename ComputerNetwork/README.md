# Computer Networks — Learning Guide

This folder is a concise learning and revision guide for **Computer Networks**.

The purpose of this section is to document important **networking terminologies, protocols, concepts, and communication mechanisms** in a simple and easy-to-understand format.

This folder covers topics such as:

* OSI and TCP/IP Models
* IP Addressing and Subnetting
* TCP and UDP
* HTTP and HTTPS
* DNS
* DHCP
* Routing and Switching
* Network Security Basics
* Sockets and Ports
* Network Devices and Protocols
* Common networking concepts asked in technical interviews

The goal is to understand **how systems communicate with each other over a network**, while maintaining concise notes that are easy to revisit and revise.
