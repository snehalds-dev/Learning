# System Design — Learning Guide

This folder is a structured learning and revision guide for **System Design** concepts.

The purpose of this section is to document important **terminologies, architectural concepts, design principles, components, patterns, and trade-offs** involved in designing scalable and reliable systems.

Use this folder to:

* Understand fundamental System Design terminology and concepts.
* Learn how commonly used components such as databases, caches, queues, load balancers, and APIs fit into a system.
* Understand scalability, availability, reliability, consistency, and performance trade-offs.
* Document High-Level Design (HLD) and Low-Level Design (LLD) concepts.
* Keep simplified notes and examples for quick revision before interviews.
* Practice breaking complex systems into smaller, understandable components.

The goal is to build a **strong conceptual foundation** and make System Design topics easier to understand, revisit, and apply during interviews or real-world development.
