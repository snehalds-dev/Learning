# Java — Learning Guide

This folder is a concise learning and revision guide for **Java programming and core Java concepts**.

The purpose of this section is to document important **Java terminologies, language features, concepts, APIs, and programming principles** in an easy-to-understand and revision-friendly format.

Use this folder to:

* Revise Java fundamentals and core programming concepts.
* Understand Object-Oriented Programming concepts and their implementation in Java.
* Document important Java keywords, features, and commonly used APIs.
* Review Collections, Exception Handling, Generics, Multithreading, Streams, and other important Java concepts.
* Maintain examples and explanations for concepts that are useful in development and technical interviews.
* Quickly revisit concepts when preparing for coding interviews or working on Java projects.

The goal is to keep the material **simple, practical, and easy to revise**, while gradually building a strong foundation in Java.
